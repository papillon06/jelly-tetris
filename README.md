# Jelly Drop · 软体果冻俄罗斯方块

根据 [果冻俄罗斯方块_视频复刻关键词.md](./outputs/果冻俄罗斯方块_视频复刻关键词.md) 与原始参考录屏复刻的可玩 + 视频动作演示 Web 游戏（纯原生 ES Modules + HTML5 Canvas 2D 软体物理求解器，零外部运行时依赖）。

## 核心特性

1. **一体成型半透明糖果凝胶外观（`dist/gel-renderer.js`）**
   - 连续外轮廓提取与二次样条平滑采样，去除一切内部小方格接缝。
   - 高饱和通透玫粉、宝蓝、明黄、青蓝等果冻材质，圆润厚边、内部柔和折射、底缘加深。
   - **角落白色高光随形变与旋转实时跟随**（通过局部形变雅可比矩阵变换椭圆高光）。
2. **真 2D 共旋软体物理引擎（`dist/soft-physics.js`）**
   - **0.5 格细分网格弹簧质点系统**：包含结构弹簧、剪切对角弹簧与跨格弯曲纤维，使 T 形横臂、L 形转角在冲击与悬空时产生连贯弯曲。
   - **有向面积守恒（泊松横向鼓起）**：触底或碰撞受压时，接触面先压扁、侧边自动鼓起，随后以约 3.5Hz 欠阻尼弹性回弹并呈 2～3 次衰减余晃。
   - **极分解共旋形状记忆与重心失衡歪倒**：实时提取软体最佳旋转角 $\theta$，不锁死水平或整数格；当支撑不足或落点偏斜时，受重力力矩作用绕支点先弯曲再自然歪倒翻向空位。
   - **复合软圆盘体积碰撞与互相挤动**：已落地的果冻始终保持动态软体状态，新落下或歪倒的果冻能把下方/侧面的果冻挤压推开，使其侧向滑入相邻空位。
3. **满行消除与残块重堆叠**
   - 按容器横向带状区域的实际变形果冻覆盖率判定满行，支持倾斜、变形、被挤入空位的果冻参与填充。
   - 消除后未消除部分自动按连通性拆分为独立软体残块，失去支撑的上层果冻继续受重力落下、歪倒并重新堆叠。
4. **三种内置模式**
   - **自由畅玩**：实时操控下落果冻移动、正逆旋转、加速/快速落下。
   - **17s 视频同款复刻演示**：按参考视频动作顺序自动演绎 5 块果冻下落、挤压、歪倒、二次滑动及白昼太阳→黄昏→弯月夜色渐变。
   - **歪倒与挤位实验**：分步特写展示“斜撞肩部把底部果冻挤入左侧空位并满行消除”与“悬空台阶重心失衡大幅歪倒翻入右侧空位”。

## 本地运行与测试

```sh
npm start
```

浏览器打开 `http://127.0.0.1:4178` 即可游玩或观看演示；打开 `http://127.0.0.1:4178/../tests/physics-preview.html` 可查看 4 组独立物理检验分镜。

```sh
npm test
```

36 项自动化测试全部通过，覆盖整块无接缝轮廓、重力加速与触底压扁鼓起、重心失衡歪倒、碰撞把已落地果冻挤入相邻空位、横向铺满消除及上层果冻失稳下落重堆叠。
