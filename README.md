# Jelly Drop · 果冻弹弹乐

按用户提供的视频参考改造的 Canvas 小游戏。整块相连的果冻轮廓、连续加速下落、碰撞压缩、非线性弯曲、二次回弹及横向惯性；四列大块棋盘，满行消除。

## 本地运行

```sh
npm start
```

打开 http://127.0.0.1:4178 。无需安装依赖。

## 操作

- 左右方向键移动，上方向键旋转，下方向键加速。
- 空格快速落下，P 暂停或继续。
- 手机点击控制按钮，也可在棋盘左右滑动、轻点旋转、向下滑动落下。
- 正常触底后有 420ms 调整窗口，快速落下直接提交。
- 填满横向一行即可消除；每 10 行升级；顶部无法放入新块时结束。
- 最佳分数和音效偏好保存在本机浏览器。

## 实现

- `dist/gel-engine.js`：连续位置和加速度、网格占用、碰撞、消行、积分。
- `dist/gel-renderer.js`：去除内部边界的整块轮廓、连续果冻材质与随形变移动的高光。
- `dist/app.js`：接触弹簧、弯曲、回弹、侧滑、消行残块各自下落、触控与音效。
- `dist/engine.js`：保留原版规则模块及共享形状定义。

视觉使用整块弹性形变，最终占用与消行仍按隐藏网格判定；不属于任意角度堆叠的通用软体物理求解器。
