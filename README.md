# Jelly Drop · 果冻俄罗斯方块

无需安装依赖的 Canvas 网页小游戏。柔软半透明果冻材质、落地压缩回弹、横向惯性晃动、满行消除、连击与音效。

## 本地运行

```sh
npm start
```

打开 http://127.0.0.1:4178 。

## 操作

- 左右方向键：移动；上方向键：旋转；下方向键：加速。
- 空格：直接落下；P：暂停或继续。
- 手机使用触控按钮，或左右滑动移动、轻点旋转、向下快滑落底。
- 满一行消除；每消除 10 行升级；堆满顶部结束。
- 个人最佳和音效偏好保存在本机浏览器。

## 实现

`dist/engine.js` 负责网格规则，`dist/jelly.js` 负责果冻材质，`dist/app.js` 负责弹簧动画与交互。反弹和滑动是视觉弹性，逻辑落点保持网格对齐，确保满行消除可预测。

## 验证

```sh
npm test
```

13 项规则测试覆盖随机袋、碰撞、旋转、软降与硬降、单行及四行消除、连击、等级、锁定延迟、暂停和重开。浏览器试玩验证移动、旋转、落底、暂停、帮助、重开及窄屏按钮；没有外部字体、图片或脚本依赖。
